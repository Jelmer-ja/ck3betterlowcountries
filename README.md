An overhaul mod for the Low Countries region. The current features are as follows:

* New culture setup with two new cultures, Picard and Walloon, as well as a reworked Frisian culture. Picard and Frisian each have a new unique tradition.
* New title localization in Dutch, French, Walloon, Picard and Frisian for the Low Countries region
* A new de jure setup with Picardy as a separate duchy
* Three new realm decisions (Unite the Netherlands, A New Frisian Kingdom and Picard Nationhood).
* New special buildings for the Low Countries region and northern France. Some of these are nerfed versions of buildings taken from Europa Magnifica, others are original.

Currently in development:
* Lists of personal names for Picard and Walloon
* Various folklore-related events and characters
* 867 start date bookmark
* Balancing the various new bonuses

Most changes are of the mod's changes in the on_action script, so the mod should be compatible with almost every other mod that doesn't also change the de jure structure of France. However, the Picard unique building might not be triggered if other mods are used due to the overriding of the building list.
